# combat_sample

```sh
flutter config --enable-dart-data-assets
```



## Running

```sh
# The game.
#   WASD move · hold RIGHT mouse and drag (or swipe) = camera
#   left button = strike (tap again to chain a 3-hit combo)
#   Shift + left button / F = heavy spin · Space = roll
#   middle mouse / Tab = lock-on toggle · Q = cycle target
#   1 / 2 / 3 / 4 = fire gush / lava pit / wind blast / shield
#   Esc = skill menu
dart run flutter_scene:init
flutter run 

```
