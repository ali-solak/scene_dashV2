# combat_sample

A knight against waves of barbarians, built on Scene-Dash and
`flutter_scene`.

## Running

```sh
flutter config --enable-dart-data-assets   # once per machine
dart run flutter_scene:init
flutter run --enable-flutter-gpu
```

## Controls

```text
WASD                          move
hold right mouse + drag       camera (or swipe)
left mouse                    strike; tap again to chain a 3-hit combo
Shift + left mouse / F        heavy spin
Space                         roll
middle mouse / Tab            lock-on on/off
Q                             next target
1 / 2 / 3 / 4                 fire gush / lava pit / wind blast / shield
Esc                           skill menu
```
